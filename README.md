# YouTube Proxy Node Collection 🚀

Автоматически валидированный список проверенных прокси-серверов (VLESS Reality, Trojan, Shadowsocks, VMess), протестированных на доступность сервисов **YouTube** и серверов потокового видео **Googlevideo CDN**.

### Как использовать в клиентах:
1. **v2rayNG (Android):** Меню (≡) ➔ «Группы подписок» ➔ Нажмите + ➔ Вставьте ссылку выше ➔ В главном окне нажмите три точки ➔ «Обновить подписку».
2. **NekoRay / NekoBox (Windows / Android):** Preferences ➔ Groups ➔ Add ➔ Type: Subscription ➔ Вставьте URL ➔ Update.
3. **v2rayN (Windows):** Меню «Подписка» ➔ «Настройка подписки» ➔ Добавить ➔ Вставьте URL ➔ «Обновить подписку».

---

## ⚙️ Методика проверки серверов

Каждый сервер проходит 3-этапную фильтрацию:
1. **Быстрый TCP Ping:** Отсев недоступных хостов.
2. **Тест реальной задержки (v2rayNG delay test):** Проверка ответа HTTP 204 через локальное ядро Xray.
3. **Глубокая проверка сервисов YouTube:** Запрос к основным веб-узлам YouTube и серверам CDN потокового видео (извлеченным из базы ByeByeDPI).
