# 🎥 YouTube Proxy Checker & GitHub Auto-Sync

Автоматизированный инструмент для поиска, тестирования и выгрузки проверенных прокси (VLESS Reality, Trojan, Shadowsocks, VMess), специально оптимизированных для работы с сервисами **YouTube** и серверами потокового видео **Googlevideo CDN**.

---

## 📌 Постоянная ссылка на подписку:

```text
https://raw.githubusercontent.com/MAS-RUB/pt/main/ytbprx.txt
```

> **Совет:** Эту ссылку можно напрямую вставить в мобильные и десктопные клиенты в качестве автоматически обновляемой подписки.

### Настройка в клиентах:
1. **v2rayNG (Android):**
   - Меню (≡) ➔ **«Группы подписок»** ➔ Нажмите **`+`**.
   - Вставьте ссылку в поле **«URL подписки»**.
   - На главном экране нажмите меню (три точки) ➔ **«Обновить подписку»**.
2. **NekoRay / NekoBox (Windows / Android):**
   - **Preferences** (Настройки) ➔ **Groups** (Группы) ➔ **Add** (Добавить).
   - Выберите тип: **Subscription**.
   - Вставьте URL и нажмите **Update** (Обновить).
3. **v2rayN (Windows):**
   - Меню **«Подписка»** ➔ **«Настройка подписки»** ➔ **«Добавить»**.
   - Вставьте ссылку и нажмите **«Обновить подписку»**.

## ⚙️ Архитектура и методика проверки

Проверка выполняется в 3 последовательных этапа:

```
[Подписки subscription.txt] + [Локальный proxy.txt]
                      │
                      ▼
            [1. Быстрый TCP-Ping] ──(отсев неактивных хостов)──►
                      │
                      ▼
    [2. Тест реальной задержки (v2rayNG)] ──(HTTP 204 <= 2500ms)──►
                      │
                      ▼
   [3. Проверка сервисов YouTube и CDN] ──(YouTube + googlevideo)──►
                      │
                      ▼
    [Сохранение в ytbprx.txt & Автовыгрузка на GitHub через API]
```

1. **Шаг 1: Быстрый TCP-пинг хостов:**
   - Высокоскоростной асинхронный опрос сетевых сокетов для мгновенного отсева недоступных серверов без перегрузки процессора.
2. **Шаг 2: Тест реальной задержки (как в v2rayNG):**
   - Запуск локального инстанса ядра Xray для каждого прокси.
   - Запрос `HTTP 204` к тестовому серверу Cloudflare (`http://cp.cloudflare.com/generate_204`).
   - Отбор только фактически функционирующих туннелей с замером точного времени задержки.
3. **Шаг 3: Глубокая валидация сервисов YouTube:**
   - Проверка доступности 12 ключевых веб-узлов YouTube (`youtube.com`, `youtu.be`, `i.ytimg.com`, `googleapis.com`, `yt3.ggpht.com` и др.).
   - Проверка CDN потокового видео (`rr*.googlevideo.com`), извлеченных из актуальной базы ByeByeDPI.
4. **Шаг 4: Выгрузка на GitHub:**
   - По завершении чека файл `ytbprx.txt` автоматически обновляется в репозитории `https://github.com/MAS-RUB/pt` через GitHub REST API с использованием Personal Access Token.

## 📚 Справка по работе с GitHub и Git

### Основные понятия:
- **Repository (Репозиторий):** Хранилище файлов проекта на серверах GitHub (в данном случае `MAS-RUB/pt`).
- **Main / Master:** Основная ветка репозитория, откуда берутся актуальные файлы.
- **Personal Access Token (PAT):** Секретный ключ для авторизации программ и скриптов в GitHub API (пароли от учетных записей GitHub через терминал и API больше не поддерживает из соображений безопасности).
- **Raw URL:** Прямая ссылка на сырое текстовое содержимое файла в репозитории (`https://raw.githubusercontent.com/...`), идеальная для клиентов VPN-подписок.
